## Reproduce

Run from the repository root in PowerShell:

```powershell
$env:RAYON_NUM_THREADS = '2'
python -m unittest discover -s scripts -p test_factory.py
python scripts/factory.py check
cargo test --locked --no-default-features -j 2 -- --test-threads=2
cargo clippy --locked --no-default-features --all-targets -j 2 -- -D warnings
cargo fmt --all -- --check
# The preceding test run builds this baseline CLI executable on Windows.
foreach ($name in @('two-panel', 'local-ease', 'tshirt', 'dress', 'curved-panels', 'partial-chain')) {
    & .\target\debug\cloth-template.exe validate "examples/templates/$name.json"
    if ($LASTEXITCODE -ne 0) { throw "Template validation failed: $name" }
}
```

The ordinary `scripts/check-cpu.ps1` stops at its first failure. The audit ran
its independent CPU commands separately so an existing formatting failure did
not hide the numerical and document tests. Do not interpret that separation as
an overall green check or relax the CI gates.
